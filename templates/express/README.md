# Midtrans Integration — Express Template

Generated by **midtrans-kit** (`midtrans init express`).

## Setup

```bash
npm init -y
npm i express
# add "type": "module" to package.json
cp .env.example .env      # fill in your keys
node --env-file=.env server.js
```

Open http://localhost:3000, click a product, pay in sandbox
(card `4811 1111 1111 1114`, CVV `123`, OTP `112233`).

## Endpoints

| Method | Path | Role |
|---|---|---|
| POST | `/api/payment/create` | `{itemId}` → `{orderId, token, redirectUrl}` (price resolved server-side) |
| POST | `/api/payment/webhook` | Midtrans notification handler (signature-verified, idempotent) |
| GET | `/api/payment/status?order_id=` | order status + reconcile against the Midtrans status API |

## Test the webhook locally

```bash
midtrans webhook:test --status settlement --url http://localhost:3000/api/payment/webhook
midtrans webhook:test --tamper --url http://localhost:3000/api/payment/webhook   # must 403!
```
